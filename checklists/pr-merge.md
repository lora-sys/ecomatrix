# PR Merge Checklist

Owner runs before clicking **Merge**; Coordinator audits after.

- [ ] PR title is conventional (`type(scope): description`).
- [ ] Linked Issue present.
- [ ] Evidence pack complete (see `checklists/evidence-gate.md`).
- [ ] All reviewer threads resolved or explicitly deferred.
- [ ] Branch is up to date with `main` (rebase, not merge).
- [ ] CI is green on the latest commit.
- [ ] No `WIP`, no `DO NOT MERGE`.
- [ ] At least one approving review from a non-author.
